# Netflix Content Portfolio Analysis

## About the Project

This project is a content portfolio analysis of the Netflix catalog. It looks at how Netflix's content strategy changed over time, which countries and genres dominate the catalog, how TV Shows are structured, and which audience ratings are most common.

## Technologies Used

- **Python 3**: programming language
- **Google Colab**: cloud notebook environment
- **pandas**: cleaning, date parsing, grouping, pivot tables (`crosstab`), splitting and exploding multi-value columns
- **matplotlib**: line, bar, grouped bar and stacked bar charts
- **zipfile / wget**: downloading and extracting the dataset
